YouTube → NewPipe

  1. JSON with handles is quickest. Importable in NewPipe through Import from → Previous export.
  2. JSON with resolved IDs also looks up each UC… id. Takes about 10 seconds for 950 channels. This is the format every importer accepts.
  3. CSV gives the same resolved ids as Google Takeout's subscriptions.csv.
  4. Each button does the whole job itself. Nothing needs pressing first, and repeat clicks reuse what was already fetched.
Which file do I import?

In NewPipe: Settings → Content → Import/Export → Import from → Previous export, then choose the JSON file.

The CSV is Google Takeout's subscriptions.csv format, for tools that expect Takeout, or for NewPipe's Takeout import.

Takeout-based importers need UC… ids, which is what the CSV and the resolved JSON provide. The handle JSON carries @handle URLs instead and is for NewPipe's own import.
